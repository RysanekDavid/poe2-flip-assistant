## Flagged disagreements / unresolved conflicts

- **Omen of Chaotic Effectiveness** — Game8 claims it's obtainable "by visiting the Currency Exchange NPC in every Act." This is contradicted by poe2scout's own "ritual" taxonomy and the general Ritual-sourcing convention for the whole Omen family, and no other source corroborates a vendor/NPC drop. Treated as unreliable; kept as Ritual/confirmed.
- **Distilled Emotion vs. Liquid Emotion** — sources use the two names interchangeably for what looks like the same Delirium currency family, but no source explicitly confirms they're synonyms rather than distinct pools. Flagged unverified.
- **Flawless Breachstone** — no 0.5-era acquisition chain was found in any Genesis Tree guide. Do not carry over PoE1's "Blessing of" upgrade-item assumption without further research.
- **Aldur runes (Flux/Passion/Breath/Ire/Betrayal of Aldur)** — intuitively expected to tie into the Runes of Aldur league mechanic (Runic Remnants), but the only documentation found describes them as plain world drops. Unconfirmed against patch notes; treat with caution for hunt-alert logic.
- **Omen of Light's exact mislabeled ninja category** — pass 1 describes poe.ninja filing it under "Ritual"; passes 2/3 (backed by a live poe.ninja URL check for the sibling item Head of the King) describe the actual bucket as a generic, mechanic-agnostic **"Omens"** tab. All three agree on the real source (Abyss); only the precise name of the mislabeled category differs slightly. The "Omens" description is treated as more precise since it's grounded in a confirmed live URL pattern.
- **Tecrod's Gaze** — one older poewiki.net (PoE1-style) page claims an additional Abyssal Trove/Stygian Spire source; this predates 0.5 and was not reconfirmed. Kept as a footnote on the main Abyss table row, not folded into the confirmed farm method.
