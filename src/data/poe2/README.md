# Local PoE2 game-data snapshot

`repoe/manifest.json` and its content-addressed compressed artifact are generated by:

```bash
npm run sync:poe2-data
```

The sync discovers and downloads every root-level RePoE `.min.json` export for the current PoE2
version, including the complete item/crafting sources used by Coach. It writes only after
validating record counts and known invariants. The immutable artifact is published first and the
manifest last, so an interrupted refresh cannot invalidate the previous snapshot.

The manifest pins its own schema, payload schema, RePoE version, source count, per-source record
counts, artifact byte length and SHA-256. The loader requires a direct content-addressed child
artifact, rejects path traversal/symlinks, and revalidates the immutable bytes for every readiness
probe. A changed or damaged snapshot therefore makes `/health` report item data unavailable even
when the parsed catalog was previously cached.

Source: [RePoE PoE2 exports](https://repoe-fork.github.io/poe2/), generated from Path of Exile 2
game data. Path of Exile is a trademark of Grinding Gear Games. This project is not affiliated
with or endorsed by Grinding Gear Games. Modifier spawn weights are not complete in the PoE2
client data, so the catalog must not be used to claim exact crafting probabilities.

RePoE contains special modifier records but not every currency-to-item-class target table. Coach
therefore cross-checks Alloy and non-natural Essence outcomes against the current PoE2DB tables in
`services/coach/src/items/alloy.py` and `essence.py`. Catalog loading fails if either reviewed ID
set changes, preventing a new patch from silently applying a Staff outcome to a quarterstaff,
jewellery, or armour.
